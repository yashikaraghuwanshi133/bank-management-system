# Bank Management System - Project Statement

## 1. Problem Statement

Managing bank account information manually can be time-consuming and may lead to errors in maintaining customer records and transaction details.

The Bank Management System is a Python-based application designed to provide a simple way to manage basic banking operations. It allows users to create and manage accounts and perform common banking operations through a simple menu-driven interface.

## 2. Scope of the Project

The scope of this project includes:

- Creating new bank accounts.
- Viewing account details.
- Searching for an account.
- Depositing money into an account.
- Withdrawing money from an account.
- Checking account balance.
- Updating account information when required.
- Storing account information for future use.
- Providing a simple menu-driven interface.

The project is intended for basic banking record management and can be extended in the future with features such as database integration, transaction history, online banking, and a graphical user interface.

## 3. Target Users

The system is mainly intended for:

- Bank employees for managing basic customer account records.
- Customers for performing basic account-related operations.
- Students and learners for understanding the implementation of banking operations using Python.

## 4. High-Level Features

The main features of the Bank Management System are:

- **Create Account:** Create a new bank account and store customer details.
- **View Account:** Display the details of an existing account.
- **Search Account:** Find an account using relevant account information.
- **Deposit Money:** Add money to an account balance.
- **Withdraw Money:** Withdraw money from an account if sufficient balance is available.
- **Check Balance:** Display the current account balance.
- **Update Account:** Modify existing customer or account information.
- **Data Storage:** Store account information for future access.
- **Simple Interface:** Provide a straightforward menu-based interface for users.
