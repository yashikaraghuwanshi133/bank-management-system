# Bank Management System

A simple Python project to manage bank accounts and transactions.

## Features

- Create account
- View accounts
- Search account
- Deposit money
- Withdraw money
- Check balance
- Save account data in a text file

## Technologies Used

- Python
- Object-Oriented Programming
- Classes and Objects
- Lists
- Loops
- Conditional Statements
- File Handling
- User Input

## Requirements

Python 3.x

No external libraries are required.

## How to Run

Open the project folder and run:

python main.py

## Project Files

- `main.py` - Main program
- `account.py` - Account class
- `bank_manager.py` - Manages bank accounts
- `accounts.txt` - Stores account data
- `README.md` - Project information
